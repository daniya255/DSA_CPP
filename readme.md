# 🚀 Data Structures & Algorithms in C++

Welcome to my **DSA in C++** repository! This repository serves as a comprehensive collection of data structures, algorithms, and problem-solving patterns implemented in modern C++.

## 🚀 Getting Started

If you want to run or test any of the files locally, follow these simple steps:

### 1. Clone the repository
```bash
git clone https://github.com/daniya255/DSA_CPP.git
cd DSA_CPP
```

### 2. Compile and Run a file
Navigate to the specific directory and compile using `g++`:
```bash
g++ -std=c++17 filename.cpp -o output
./output
```
*(On Windows, use `output.exe` instead of `./output`)*

* **Modularity:** Reusable logic and clean separation of concerns.
